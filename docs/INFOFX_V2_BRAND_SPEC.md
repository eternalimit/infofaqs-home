## Identity and scope
InfoFx is a distinct, proposed companion brand alongside InfoFAQs. It does **not** rename InfoFAQs, transfer ownership, replace the existing homepage, change DNS or email routing, or grant public-release authorization.

## Proposed V2 workstreams
1. **Brand:** Design an InfoFx wordmark, accessible contrast palette, and explicit InfoFAQs attribution; review naming/trademark clearance before public claims.
2. **Navigation:** Prototype a leaf-level InfoFx entry, with an optional return link to InfoFAQs. No homepage changes without review.
3. **THE CUBE:** Describe optional connections to MASTER.ORIGIN, CATBOT 100, and evidence receipts without claiming operational integrations.
4. **Trusted Marketplace:** Draft host and registrant roles with explicit opt-in, access control, and privacy review. No implied signed agreements.
5. **Email:** Test you@infofaqs.com from a genuinely separate mailbox; inspect ImprovMX aliases, SPF, DKIM, DMARC and forwarding outcomes. Do not change MX/DNS without a verified plan.
6. **Quality:** Validate desktop/mobile navigation, accessibility, privacy/security, CI and rollback.
7. **Receipts:** Record exact commit, test run URLs, deployed artifact identity and SHA-256 only after independent verification.
